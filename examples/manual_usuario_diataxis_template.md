## 1. Instalación y Configuración (How-To Guide)
*(Solo aplicable si el usuario final debe desplegar o instalar componentes en su estación de trabajo).*

### 1.1 Requisitos Mínimos
* **Navegador Web:** Google Chrome v110+, Mozilla Firefox v115+ o Microsoft Edge v110+.
* **Conectividad:** Conexión a red local o Internet con ancho de banda mínimo de 5 Mbps.

### 1.2 Procedimiento de Acceso / Instalación Paso a Paso
1. Abrir el navegador e ingresar a la URL: `https://app.sistema.local`.
2. Verificar que el certificado de seguridad SSL esté activo (candado cerrado).
3. Si requiere cliente de escritorio, ejecutar `Instalador_Sistema.exe` y seguir las instrucciones del asistente.

## 3. Guía de Funcionalidades por Casos de Uso (How-To Guides por Rol)

### Rol: [Nombre del Rol 1 - ej. Operador / Cliente]

#### 3.1 [Funcionalidad Crítica 1 - ej. Registrar una Nueva Solicitud]
* **Objetivo:** Permite al operador ingresar una solicitud en el sistema.
* **Paso a Paso:**
  1. Dirigirse al menú lateral y hacer clic en **"Nueva Solicitud"**.
  2. Completar los campos requeridos marcados con asterisco (*): *Nombre, Identificación, Motivo*.
  3. Adjuntar los documentos soporte en formato PDF haciendo clic en **"Examinar"**.
  4. Presionar el botón **"Guardar y Enviar"**.
  5. El sistema mostrará un mensaje de éxito: *"Solicitud #1234 registrada satisfactoriamente"*.

## 4. Solución de Problemas (Troubleshooting y Referencia)

### 4.1 Problemas Frecuentes y Soluciones Inmediatas
| Síntoma o Mensaje de Error | Causa Probable | Solución Recomendada |
| :--- | :--- | :--- |
| *"Credenciales inválidas"* | Contraseña incorrecta o usuario bloqueado. | Verificar el teclado (mayúsculas activadas) o usar la opción "Recuperar Contraseña". |
| *"Error de conexión con el servidor"* | Caída momentánea de red o servicio. | Comprobar conexión a Internet y recargar la página (Ctrl + F5). Si persiste, contactar a soporte. |

### 4.2 Acciones ante Fallos Inesperados
En caso de pantallas de error del sistema (código 500), tomar una captura de pantalla completa e informar al administrador adjuntando la hora exacta del incidente.
